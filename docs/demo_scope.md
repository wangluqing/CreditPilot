# CreditPilot V0.1 演示范围

## 数据范围

演示仅使用原创合成的客户画像、规则、评分、决策与文档案例，不收集、导入或处理真实客户及征信数据。

## 模拟规则与评分边界

规则命中、风险评分与模拟决策必须由可测试、可追溯的确定性 Python 模块产生。模拟结果只验证工程流程，不代表真实信用风险预测能力；证据不足时应返回 `UNKNOWN` 或 `NEEDS_REVIEW`。

## 决策辅助定位

LLM 仅可用于意图理解、工具编排和基于已有证据的解释表达。规则拒绝原因与模型风险因素必须区分，最终真实业务决策始终由授权人员负责。

## 禁止真实业务操作

本项目不得连接真实信贷系统，不得执行真实审批、拒绝、额度调整或客户数据写入，也不得在未经明确授权时调用真实外部 API。

## 公开 GitHub 安全原则

公开前检查 Git 历史、工作区、密钥、日志、数据库、模拟数据来源和许可证。不得提交 `.env`、真实 API Key、敏感日志、真实业务数据或前雇主保密资料；README 仅描述已实现且已验证的能力。
